# Tarang Portfolio

This context defines the language for presenting Tarang Goyal's work, credibility, and contact paths in the portfolio.

## Language

**Portfolio Visitor**:
A recruiter, founder, investor, collaborator, or event organizer evaluating Tarang's work.
_Avoid_: Authenticated product user, analytics session

**Positioning**:
The concise statement of Tarang's primary professional focus as an AI Product Engineer / Forward-Deployed Engineer. Product management and analytics are differentiating capabilities that support this identity.
_Avoid_: Job title history, project description

**Experience Entry**:
A verifiable role, responsibility, or achievement associated with an organization and time period.
_Avoid_: Project Entry, unsupported claim

**Project Entry**:
A selected product or technical build presented with its problem, contribution, and evidence.
_Avoid_: Repository link without context, Experience Entry

**Proof Artifact**:
A public repository, live deployment, paper, award, screenshot, or document that supports an Experience Entry or Project Entry.
_Avoid_: Decorative asset, unverified metric

**Case Study**:
A structured explanation of a problem, Tarang's decisions, the implementation, and the observed result.
_Avoid_: Feature list, image gallery

**Hackathon Win**:
An award with an identifiable event and outcome. It should link to a Proof Artifact when one is available.
_Avoid_: Participation, self-assigned badge

**Resume Artifact**:
The canonical downloadable resume served from `public/resume.pdf`.
_Avoid_: Page copy, generated profile summary

**Contact Path**:
An intentional route for a Portfolio Visitor to reach Tarang through a published professional channel.
_Avoid_: Secret credential, analytics identifier

**Visual Showcase**:
The evidence-editorial layer that uses real product interfaces, annotated decisions, and proof artifacts to communicate craft.
_Avoid_: Decorative WebGL in the critical path, unsupported metrics, navigation state

**Decision Trace**:
A repeatable case-study structure: observed problem, product decision, shipped system, and contextual proof.
_Avoid_: Feature list, desired outcome presented as measured evidence

**Flagship Project**:
One of three deeply evidenced projects selected to prove Tarang's primary positioning: Studentlytics, Morphic, or Locus.
_Avoid_: Every live link receiving equal visual weight
